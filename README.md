# manu-format

`.manu` is a document format that is always editable: a single self-contained HTML file that holds both the **content** and its **editor**.

Open a `.manu` file in any browser, double-click a block to edit its Markdown, and save — the file re-serialises itself, with images and fonts embedded. It works offline, needs no install or server, and exports a true-text, paginated A4 PDF straight from the page.

Sources can also be imported and exported as plain Markdown plus images (zip or drag and drop).

`ref/initial_reference.html` is the reference implementation this repository starts from.

Status: early, private work in progress.
